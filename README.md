A family scene in 1–2 lines, at most 280 characters, that makes the AI judge feel proud. The program writes the scene to `/output/entry.txt` — nothing else, no code and no repository needed beyond this.

The entry: *"Dad ran beside my first bike shouting, "Don't look down, look where you're going!" I looked back instead — and saw him still running, three houses behind, out of breath and grinning like he'd won something."* (206 characters, one line.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: Python 3 stdlib only, no randomness, no clock, no network. Two runs produce byte-identical output.
